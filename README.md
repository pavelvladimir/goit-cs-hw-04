# GoIT CS — домашнє завдання 4

Пошук ключових слів у текстових файлах двома способами: через `threading`
і `multiprocessing`. Для порівняння швидкості додав також послідовний варіант.

## Запуск

Потрібен Python 3.14. Сама програма працює без сторонніх бібліотек.
Команди запускаються з кореня проєкту:

```bash
python3 main.py
```

Програма обробить приклади з `data/`, покаже знайдені слова та час роботи
обох версій, а потім порівняє результати. Для окремого запуску:

```bash
python3 threading_search.py
python3 multiprocessing_search.py
```

Власний каталог і слова можна передати так:

```bash
python3 main.py --directory data --keywords python процес --workers 3
python3 main.py --help
```

`--directory` знаходить усі `.txt` у каталозі та його підкаталогах.
Для конкретних файлів є `--files`, для врахування регістру — `--case-sensitive`.

Обидві версії повертають словник: ключове слово → список шляхів до файлів.
Шляхи відсортовані, повторів немає, для слова без збігів повертається `[]`.
Пошук працює з UTF-8 і шукає підрядки: наприклад, `process` знайдеться
в `multiprocessing`. За замовчуванням регістр не враховується.
Якщо файл не вдалося прочитати, програма повідомить про це й продовжить з іншими.

## Перевірки

Для розробки використовую uv, pytest, Ruff і mypy. Потрібні uv та Make:

```bash
make init
make check
make benchmark
```

`make check` запускає перевірки коду, документації та тести з покриттям.
`make benchmark` порівнює послідовний пошук, потоки й процеси.
Додатково є `make check-rocky` — ті самі перевірки в Rocky Linux через Docker,
як у ДЗ2.
