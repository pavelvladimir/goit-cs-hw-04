# Перевірка в Rocky Linux

Як і в ДЗ2, додав перевірку в Rocky Linux. Потрібні Make та запущений Docker;
Python і uv на хості для цього не потрібні.

```bash
make check-rocky
```

Команда збирає локальний образ `goit-cs-hw-04-rocky-tests` і запускає в ньому
перевірки коду, тести та demo. Якщо щось не проходить, команда завершується
з помилкою. Повторна збірка використовує кеш, але підхоплює зміни вихідних файлів.

У `docker/tests.Dockerfile` зафіксовані образи Rocky та uv через digest,
Python — версією 3.14.6, Python-залежності — через `uv.lock`.
Make і Git встановлюються з репозиторіїв Rocky, тому повністю ідентична збірка
з часом не гарантується.

Під час збірки потрібна мережа для завантаження залежностей. Самі тести працюють
без мережі й root, із read-only файловою системою та тимчасовим `/tmp` на 256 MiB.
Каталоги хоста й Docker socket не підключаються. Кеші, `.env` та локальні звіти
не передаються до образу.

Після запуску контейнер видаляється, образ залишається локально.
Coverage-звіти всередині контейнера теж тимчасові.

За потреби журнал можна зберегти так, у Bash:

```bash
mkdir -p artifacts
set -o pipefail
make check-rocky 2>&1 | tee artifacts/check-rocky.log
```

Перевірено Rocky Linux 10.2 ARM64 у Docker Desktop: 91 тест пройшов,
покриття — 100%. Це перевірка Linux-оточення в контейнері, не нативної
інсталяції Rocky/RHEL чи SELinux enforcing.
